# VITYARTHI-Project-Python-Essentials
Book Library Management System
Overview of the Project :
This is a Command Line Interface (CLI) application built using Python and Object-Oriented Programming (OOP) principles. The primary goal of this project is to create a simple, functional system for a small library to manage its inventory of books. The system allows library personnel to efficiently track books in stock and manage their circulation status (checked out or available).
Features:
Book Management: Easily add new books to the inventory, recording the Title, Author, and ISBN.
Inventory Listing: Display a complete and organized list of every book currently in the library.
Intelligent Search: Quickly locate books using a partial and case-insensitive search based on the title.
Circulation Control: Dedicated functions for checking out and returning books.
Real-time Status: Every book maintains an accurate and up-to-date status (Available or Checked Out).
Tools Used:
Component, Technology/Tool, Purpose

Data Structure, Python List, Used as the in-memory database to store all Book objects.

Steps to Install & Run the Project:
Prerequisites
You must have Python 3.x installed on your operating system.
Installation:
No complex installation is needed.
Save the entire code provided (the Book and Library class definitions, along with the example usage block) into a single file named library_management.py.
Running the Project:
Open your terminal or command prompt.
Navigate to the directory where you saved the library_management.py file.
Execute the script using the Python interpreter.
